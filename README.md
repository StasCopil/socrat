# SOCRATES // EXECUTIVE DIALECTIC CORE (V2.0)

Интеллектуальная система стратегической деконструкции и закалки мышления по методу Сократа (*elenchus* и *майевтика*).

Вместо банальных ответов или поучений система выступает в роли безжалостного спарринг-партнера: вы закладываете любую гипотезу, а движок последовательно подвергает её стресс-тесту, вскрывает скрытые допущения, тестирует контрпримерами и в реальном времени кристаллизует **Executive Blueprint**.

---

## Ключевая архитектура (Superpower Suite)

1. **Dual-Pane Executive Studio:**
   - **Слева (Arena):** Диалектический спарринг без воды. Хирургические проверочные вопросы, вскрытие скрытых аксиом и контр-ракурсы.
   - **Справа (Canvas):** Живой холст **Executive Blueprint** в реальном времени. Структура документа (*Исходный тезис ➔ Первые принципы ➔ Вскрытые слепые зоны ➔ Директивы действий*) формируется прямо в процессе диалога.

2. **Панель тактических маневров (One-Click Tactical Strikes):**
   - **Fatal Flaw** — поиск одной критической причины, почему идея потерпит сокрушительный крах в реальности.
   - **Steel-Man** — формулировка сильнейшего аргумента умнейшего критика, опровергающего тезис.
   - **Атомизация (First Principles)** — очистка от социальных аналогий «так принято» до фундаментальных законов физики и экономики.
   - **Inversion (По Чарли Мангеру)** — проверка от обратного: как гарантировать 100% провал, и какое скрытое правило это обнажает.

3. **5 Диалектических фреймворков:**
   - **Socratic Elenchus** — распаковка определений и поиск внутренних противоречий в терминах.
   - **Red Team / Fatal Flaw** — беспощадный стресс-тест, поиск иллюзии выжившего и худших сценариев.
   - **First Principles** — физика мысли и деконструкция до несводимых атомарных истин.
   - **Second-Order Strategy** — последствия второго порядка, компромиссы (trade-offs) и скрытые стимулы.
   - **Synthesis & Action Memo** — кристаллизация интуиции в четкие правила принятия решений.

4. **Индекс закалки гипотезы (Resilience Score):**
   - Динамический расчет устойчивости аргумента от 20% (первичная гипотеза) до 100% (закаленный вердикт).

5. **ИИ-движок:**
   - Google Gemini API (Gemini 1.5 Flash / 2.0 Flash / Pro) — бесплатный режим с высокой скоростью.
   - OpenAI (GPT-4o / GPT-4o-mini).
   - OpenRouter (Claude 3.5 Sonnet, DeepSeek).
   - Встроенный автономный оффлайн-движок (работает без ключей и без сети).

6. **Экспорт и синхронизация:**
   - Копирование Executive Memo в 1 клик.
   - Экспорт структурированного манифеста в Markdown (`.md`).
   - Локальная синхронизация LAN Sync / Bonjour между Mac в одной сети Wi-Fi.

## Запуск

```bash
# Обычный запуск сервера (уже собрано)
node server.js

# Или двойной клик по скрипту в Finder:
"Запустить Сократ.command"
```

Приложение открывается по адресу: `http://localhost:3000`.

## Развертывание на GitHub Pages

Проект настроен для автоматической публикации на GitHub Pages:
1. Создайте новый репозиторий на GitHub.
2. В настройках репозитория: **Settings ➔ Pages ➔ Source** выберите **GitHub Actions**.
3. Отправьте код в ветку `main`:
   ```bash
   git add .
   git commit -m "feat: initial commit"
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
4. GitHub Actions автоматически соберет проект и развернет его по ссылке `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Настройка API-ключей

В интерфейсе нажмите на иконку настроек в правом верхнем углу:
- Выберите провайдера (**Google Gemini**, **OpenAI**, **OpenRouter** или **Автономный оффлайн**).
- Бесплатный ключ Gemini можно получить в [Google AI Studio](https://aistudio.google.com/app/apikey).
- Ключи хранятся исключительно локально в браузере (`localStorage`).
